# Design

## Architecture

- Vue UI：只处理交互状态、表单校验提示和展示。
- TypeScript domain：解析、序列化、搜索、重复判断，保持为纯函数并可独立测试。
- Tauri commands：目录发现、偏好存储、文件读取和带滚动备份的原子保存。

## Data preservation

以 `...` 为词典头部与正文分界。头部原样保存；正文中的空行、注释、分组标记和无法识别的行也进入行模型，保存时原样输出。只规范化用户新建或编辑的词条。

## Safety

写入顺序为：写临时文件 → 覆盖 `.backup` → 原子重命名临时文件。应用不调用任何部署命令。
