# Change: 增加跨平台 Rime 重新部署

## Why

词典保存后仍需离开工具，通过输入法菜单手动重新部署。该步骤频繁且容易遗漏。

## What Changes

- 增加“保存并重新部署”，保存成功后调用当前平台的 Rime 部署器。
- 自动识别 Windows 小狼毫、macOS 鼠须管与 Linux `rime_deployer`。
- Linux 自动部署标记为实验性，并保留清晰提示。
- 自动识别失败时允许选择自定义部署程序、逐行填写参数并记忆配置。
- 部署失败不回滚已安全保存的词典，分别反馈保存和部署结果。

### Clarifications

- 用户确认按建议顺序实现 Windows、macOS、通用自定义命令和 Linux 实验性自动识别。
- 自定义命令不经过 Shell，配置为可执行文件与参数列表。
- 仅手动点击时执行重新部署，不开启自动部署。
