# Design

## Diagnosis

反馈环使用 Vue 公共 DOM 作为测试边界。修复前 5,000 条词典会同步生成 5,000 个 `.entry-row`，并且侧栏不存在独立的 `.dictionary-list` 滚动区域，两个断言稳定失败。

## Rendering window

内存模型和搜索结果保持完整，只将前 300 条结果映射到 DOM。用户可每次再加载 300 条；搜索词变化时重置渲染窗口。这消除了近九万个交互节点带来的主线程阻塞，同时不丢失任何词典数据。

## Sidebar layout

侧栏保持纵向布局，词典列表获得 `min-height: 0` 和独立纵向滚动；操作区禁止收缩并留在底部。
