# Simplify the editor and add appearance preferences

## Why

这是一个单文件、小频次使用的词典工具。持续列出目录中的全部词典增加了视觉和交互负担，原有窗口也偏大、装饰偏多，并且安装后的应用图标不够明确。

## What Changes

- 删除词典文件列表和选择目录入口，仅保留当前文件及选择文件操作。
- 启动时仅恢复上次选中的有效词典，失效时显示选择文件空状态。
- 将默认窗口缩小为 720×560，并改为无渐变的紧凑纯色界面。
- 增加跟随系统、浅色、深色显示模式和少量主题色，记忆用户选择。
- 设计并生成跨平台应用图标资源。

## Capabilities

- `dictionary-editing`：简化文件选择，并增加可记忆的外观偏好。

### Clarifications

- 用户确认不必列出可修改文件，只需要选择文件。
- 用户确认界面定位为简单易用的小工具。
- 用户接受“跟随系统、浅色、深色 + 少量主题色”，并要求记忆选择。
- 用户确认上次文件有效时自动打开，失效时显示选择文件空状态。
- 用户要求补充应用图标，并于 2026-09-07 明确确认“无歧义，可以开始”。
