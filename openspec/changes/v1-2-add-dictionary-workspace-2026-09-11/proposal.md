# Change: 增加跨文件词库组编辑

## Why

Rime 编码方案通常由根词典及多个 `import_tables` 词典组成。仅查询当前文件无法发现跨文件撞码，也无法直接调整导入词典中的权重。

## What Changes

- 打开一个词典时递归解析其有效 `import_tables`，加载为一个词库组。
- 搜索、精确撞码检查覆盖整个词库组，并显示词条来源文件。
- 新增词条仍写入用户当前选择的文件；已有词条可在所属文件内修改权重。
- 保存时一次提交全部已修改文件，每个文件使用单份滚动备份与原子替换。
- 搜索结果分批渲染，避免大词库组阻塞界面。

### Clarifications

- 用户确认采用建议方案，并明确“行，就按你建议的办，执行修改吧”。
- 仅解析未注释且实际存在的 `import_tables`；不加载注释掉的词典。
- 当前选择文件固定为新增词条的写入目标。
- 允许编辑词库组内任意已加载词典的词条，保存全部脏文件。
- 首版使用内存轻量索引，不引入磁盘缓存；结果最多分批渲染 100 条。
